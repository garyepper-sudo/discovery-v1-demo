# Emergent Organizational Intelligence Production-Shadow Experiment 002

## Objective

Test whether unchanged production cognition can begin with raw Evidence from
separate organizational silos, generate a relational mechanism not available
locally, and improve held-out prediction and intervention selection.

Experiment 001 established that supplied, production-shaped cross-silo
Mechanisms can create nonlinear value. It did not establish that production
cognition can create those Mechanisms. This experiment closes that scientific
gap without changing production behavior.

## Production path

Each fixture enters `runDiscoveryV3()` as production-shaped raw evidence. Its
result is passed to `evolveOrganizationRuntime()` against a fresh, in-memory
organization Runtime under a fixed clock. The replay exercises Evidence,
Signals, Themes, Observations, Contradictions, Mechanisms, Causal Chains,
Explanations, Beliefs, Hypotheses, Understanding, Phenomena, Concepts,
Theories, Conditions, Organizational State, Executive Assessment, Predictions,
and Executive Recommendation.

The benchmark adapters:

- remove the fixture-only silo field before production ingestion;
- map production Evidence lineage back to the originating silo;
- select, but never author, a qualifying generated Mechanism;
- project generated content into a user-facing verbal structure.

No Runtime is persisted. Production schemas, producers, capabilities, and
existing benchmarks are unchanged.

## Scenarios and models

Eleven neutral scenarios cover commercial complexity, decision escalation,
local optimization, customer misdiagnosis, delayed consequence, contradictory
local explanations, and five difficult negative controls.

The comparison set is:

1. best individual silo (chosen after scoring);
2. local-conclusion aggregation;
3. generic all-Evidence summary;
4. production Organizational State;
5. production full canonical combined;
6. verbal projection of model 5.

Inference Evidence, registered outputs, held-out future Evidence, and scoring
truth remain separate. Registration occurs before futures enter scoring.

## Hard gates

The twelve gates test raw-Evidence origin, cross-silo Mechanism formation,
individual non-recoverability, generic-summary superiority, held-out
prediction, intervention selection, lineage, counterfactual necessity,
negative-control abstention, determinism, fair information access, and absence
of benchmark semantic injection. Gates 1, 2, 4, 5, 6, and 12 are decisive.

## Run

```bash
npx tsx engine/benchmark/emergent-organizational-intelligence-production-shadow-experiment-002/runEmergentOrganizationalIntelligenceProductionShadowExperiment002.ts
```

The command writes deterministic `RESULTS.json`. Production currently emits a
large diagnostic trace; redirect stdout when only the summary is needed.

## Limitations

- Scenarios are synthetic and small.
- Semantic scoring uses explicit term sets after registration.
- Generic summarization is deterministic extraction, not a language model.
- Cognition ablations operate on generated artifacts after production.
- Pairwise silo removal is exhaustive for scenario 001 and deterministically
  sampled for other families to bound replay cost.
- Evidence-quality ablations use scenario 001 and are exploratory.
- The benchmark does not establish causal precondition thresholds.
