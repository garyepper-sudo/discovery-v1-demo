# Organizational Understanding Evaluator 001

Phase 1 benchmark-research infrastructure for `GAP-D-005`.

The primary comparison unit is a structured Organizational Understanding
Proposition, never ground-truth text versus treatment text. This package defines
versioned contracts, frozen semantics, scoring decomposition, fixtures, and
fail-closed interfaces only.

There is no live semantic adjudicator, candidate generator, deterministic
scorer, treatment execution path, Runtime dependency, or Production consumer.
External Comparative Validation 002 remains unauthorized.

## Phase 2

Phase 2 adds deterministic identity, authorization, graph, confidence, family,
polarity, modality, temporality, duplicate, assignment, dimension-score,
ledger, serialization, and hash behavior for already-completed imported
adjudications. It performs no semantic recovery or judgment.

The composite is calculated only when every structural gate passes and all
required imported adjudications are complete. It is inactive for comparative
execution because semantic adjudication has not been implemented or validated.

## Phase 3

Phase 3 adds treatment-neutral, deterministic, high-recall candidate generation.
It references validated Phase 2 graph identities, structural compatibility, and
duplicate ancestry, then records bounded lexical, entity, relationship,
Evidence, confidence-range, and family-specific observations. Genuine ties are
preserved; a cap cannot arbitrarily truncate a tied group.

Candidate tiers and feature scores organize retrieval workload only. They do
not express correctness, do not assign benchmark credit, and are never
consumed by the Phase 2 scorer. The generator cannot receive imported
adjudications or fixture labels. Semantic adjudication, human review, Phase 4,
and External Comparative Validation 002 remain unauthorized.
