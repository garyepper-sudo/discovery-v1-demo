# Causal Mechanism Formation Experiment 001

## Objective

This benchmark asks whether a benchmark-local producer can form complete,
discriminating, falsifiable causal hypotheses from raw distributed Evidence and
unchanged production-generated cognition. It does not change production.

## Prior findings and scientific gap

Prior experiments found useful cross-silo relationship fragments but no explicit
mediation, activation or persistence, alternatives, implications, or
falsification. This experiment tests whether fixed causal-composition rules can
form those fields without scoring truth, future outcomes, or scenario lookups.

## Input boundary and production path

Every case begins with raw `InvestigationEvidenceSource` records. The unchanged
production-shadow harness runs `runDiscoveryV3`, followed by in-memory
`evolveOrganizationRuntime`, under a fixed clock. The benchmark collects raw
Evidence plus generated Observations, Signals, Contradictions, Themes,
Phenomena, Mechanisms, Beliefs, Concepts, Theories, Conditions, and
Organizational State. A shape adapter adds no semantic content.

Candidate registration completes before held-out futures or scoring truth are
read. Candidate modules do not import either.

## Strategies

1. **Current production Mechanism** — uses generated Mechanisms as-is.
2. **Pairwise composition** — joins adjacent explicitly supported relationships.
3. **Alternative-aware formation** — adds alternatives stated in available
   Evidence.
4. **Conservative discriminating formation** — qualifies only a supported,
   multi-hop, multi-silo chain with a condition, alternative, lineage,
   implication, and falsification criterion.

No strategy is tuned by case.

## Support statuses

Fields are `explicit`, `deterministically-derived`,
`supported-but-ambiguous`, `unavailable`, or `unsupported`. Unsupported or
unavailable content is not fabricated.

## Qualification

A qualified candidate requires an upstream driver, mediator, downstream
outcome, activation condition, nonredundant multi-silo support, complete
lineage, supported direction, an alternative, a conditional implication, and a
falsification criterion. Confidence and silo count cannot qualify a candidate.

## Scenarios

Eight positives cover commercial complexity, decision escalation, local
optimization, customer misdiagnosis, delayed consequences, conditional
operation, branching, and converging structures. Nine controls cover
insufficient Evidence, directionless correlation, connectivity without causal
sufficiency, unresolved alternatives, a one-silo answer, redundant
confirmation, temporal reversal, confounding, and structural change.

## Held-out evaluation and baselines

Implications are registered before future Evidence is revealed. Comparisons
include current production Mechanisms, best silo, generic all-Evidence summary,
production Organizational State, Full Canonical Combined cognition, pairwise
composition, and conservative formation. Baselines are not weakened.

## Hard gates

The run fails on semantic leakage, missing lineage, future visibility,
unsupported fields, blanket abstention, absent positive recall, false-positive
qualification, or nondeterminism. Passing does not authorize production.

## Run

```bash
npx tsx engine/benchmark/causal-mechanism-formation-experiment-001/runCausalMechanismFormationExperiment001.ts
```

## Limitations

The fixture Evidence uses explicit, natural-language relationship statements so
the experiment isolates formation rather than relation extraction. The producer
does not resolve synonyms or implicit causal language. Branching and converging
families remain incomplete. The positive result therefore supports only a
narrow explicit-chain producer contract and requires further benchmark
refinement before any production proposal.
