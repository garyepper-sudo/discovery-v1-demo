# Localized Nonlinear Cognition Experiment 001

## Objective

This benchmark compares a stable linear architecture, localized nonlinear
cognition, and pervasive nonlinear cognition using identical semantic inputs.
It asks whether global dynamical behavior can emerge from three narrow
transition contracts while lower representation and lineage remain stable.

## Architectures

### Stable linear

Support and outcomes adjust confidence gradually. Mechanisms remain fragments or
hypotheses, activation stays static, and outcomes do not restructure the model.

### Localized nonlinear

Nonlinearity exists only at:

1. complementary, mediated Mechanism qualification;
2. qualified Mechanism × supported Condition × State interaction;
3. revision after a preregistered prediction and discriminating outcome.

### Pervasive nonlinear

Threshold promotion, condition switching, and recursive feedback apply broadly,
including redundant and irrelevant lower-level support.

## Shared input boundary

All architectures consume the same parsed raw Evidence after the unchanged
production-shadow cognition replay. Expected transitions and scoring truth are
not passed to any architecture. Candidate outputs are never recycled as
Evidence.

## Scenario families

Nineteen cases cover formation boundaries, redundant versus complementary
Evidence, converging Conditions, inhibition, amplification, state transition
and reversal, outcome-driven confirmation/alternative promotion/retirement,
multi-cycle learning, static additive reasoning, noise, false phase transition,
correlated Conditions, and self-repeating feedback.

## Localized contracts

- **Formation:** complementary support, mediation, and an alternative margin use
  fixed shared gates. Repetition cannot promote a Mechanism.
- **State interaction:** a qualified Mechanism requires independent state
  contrast and Condition support before activation, inhibition, or amplification.
- **Outcome revision:** a structural change requires a preregistered prediction,
  a discriminating outcome, lineage, and a reversal condition.

## Ablations

The benchmark removes each zone independently and tests all two-zone
combinations plus formation alone.

## Run

## Limitations

This is a controlled synthetic architecture experiment. It does not establish a
universal organizational law or solve the independent-language limitation. No
production nonlinear engine, threshold, feedback loop, state transition, or
schema is implemented.
