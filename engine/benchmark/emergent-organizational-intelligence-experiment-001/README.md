# Emergent Organizational Intelligence Experiment 001

## Purpose

This benchmark-only research experiment tests whether structured reasoning
across distributed organizational evidence can produce grounded explanations,
predictions, and interventions unavailable to any individual silo and superior
to generic aggregation.

Nothing in this directory defines production cognition, Runtime, schemas,
capabilities, APIs, or application behavior.

## Research question

Can cross-silo structured cognition create measurable value that is:

- non-local;
- compositionally necessary;
- relationally novel;
- fully traceable;
- predictively useful;
- intervention-relevant;
- counterfactually sensitive?

## Input boundary

Nine opaque synthetic scenarios contain:

- raw `SiloEvidence`;
- production-shaped `V3Mechanism` fields;
- production-shaped `V3Contradiction` fields;
- production-shaped Organizational Theory fields;
- production-shaped Organizational Condition fields;
- production-shaped Organizational State fields;
- optional historical transitions.

Expected mechanisms, outcomes, interventions, required silos, and abstention
answers are stored in a separate scoring-only collection. Future outcomes are
revealed only after registration.

The canonical and emergent models receive byte-identical inputs. Generic
summary receives every raw observation but does not consume Discovery's
structured artifacts.

## Scenario families

1. cross-functional bottleneck;
2. misdiagnosed constraint;
3. reinforcing feedback loop;
4. delayed downstream consequence;
5. contradictory local explanations reconciled by an integrated mechanism;
6. one silo already contains the answer;
7. insufficient information;
8. coincidental correlation;
9. unresolved contextual contradiction.

## Comparison models

- Best Individual Silo
- Majority Vote
- Concatenated Summary
- Latest Organizational State
- Full Canonical Combined Cognition
- Emergent Organizational Understanding projection

The final two models use the same structured inference. The Emergent model only
packages the result into the experiment-local representation. Matching
Canonical Combined therefore demonstrates compression, not a new cognitive
layer.

## Emergence rule

A candidate requires:

- one canonical Mechanism;
- supporting Evidence from at least three independent silos;
- exact Evidence lineage;
- no unresolved competing Mechanism;
- no explicit “no universal model” result;
- a supported Condition and Theory where available.

The rule generates:

- an integrated explanation;
- reconciled local interpretations;
- discovered causal relationships;
- intervention implications;
- predicted outcomes;
- confidence;
- falsification criteria.

These are experiment-local rules, not production contracts.

## Evidence-removal tests

Every silo is removed independently, followed by every pair of silos.
Confidence and candidate survival are recorded. Every scenario is also replayed
using one isolated silo at a time.

## Ablations

- historical transitions removed;
- Contradictions removed;
- Mechanisms removed;
- Theories removed;
- Conditions removed;
- lineage removed.

## Hard gates

- no production modifications;
- zero answer leakage;
- identical Canonical and Emergent information;
- Best Individual Silo outperformed;
- Generic Summary outperformed;
- prediction improvement;
- intervention improvement;
- zero false-positive emergence;
- deterministic replay;
- correct abstention;
- no individual recovery of a required multi-silo explanation.

## Run

```bash
npx tsx engine/benchmark/emergent-organizational-intelligence-experiment-001/runEmergentOrganizationalIntelligenceExperiment001.ts
```

The runner prints the full result and writes deterministic `RESULTS.json`.

## Interpretation limit

The fixtures contain benchmark-authored, production-shaped cross-silo
Mechanisms. The experiment tests whether those canonical artifacts carry
non-local value. It does not prove that the unchanged production pipeline can
generate the same Mechanisms from raw silo Evidence.

Production replay is required before claiming that current Discovery generates
Emergent Organizational Intelligence end to end.
