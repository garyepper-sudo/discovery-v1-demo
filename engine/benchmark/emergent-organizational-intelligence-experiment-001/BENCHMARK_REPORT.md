# Emergent Organizational Intelligence Experiment 001 — Benchmark Report

## Executive summary

Structured cross-silo cognition materially outperforms individual and generic
aggregation controls inside this benchmark.

Full Canonical Combined and the Emergent projection both achieve:

- explanation accuracy: `1.000000`;
- prediction accuracy: `1.000000`;
- intervention quality: `1.000000`;
- abstention quality: `1.000000`;
- false-positive emergence: `0`;
- deterministic replay: PASS.

Generic Summary achieves `0.444444` on explanation, prediction, intervention,
and abstention. Best Individual Silo produces the same accuracy.

The Emergent projection adds no value above Full Canonical Combined. The
measured value resides in cross-silo Mechanisms and lineage already represented
by structured canonical cognition, not in a new Emergent Intelligence object.

This is controlled evidence, not an end-to-end production proof. Benchmark
authors supplied the production-shaped cross-silo Mechanisms. The unchanged
production pipeline has not yet been replayed to prove it can generate them
from these raw silo observations.

## Methodology

For every scenario:

```text
Distributed inference evidence
→ canonical artifact boundary
→ six model predictions and interventions registered
→ held-out future revealed
→ scoring
```

Scoring-only fields are unavailable to inference and registration.

The models are scored for:

- cross-silo necessity;
- individual recoverability;
- explanation accuracy;
- mechanistic grounding;
- relational novelty;
- generic-summary superiority;
- prediction accuracy;
- intervention quality;
- lineage;
- counterevidence;
- abstention;
- calibration.

## Fixture provenance

Production-shaped fields are imported from:

- `V3Mechanism`;
- `V3Contradiction`;
- `OrganizationalTheory`;
- `OrganizationalCondition`;
- `OrganizationalState`.

Synthetic fields include all organizational content, silo attribution, dates,
historical groupings, and held-out futures.

The principal limitation is material: cross-silo Mechanism ancestry is
benchmark-authored. This means the benchmark begins after the hardest upstream
formation question has been partly answered.

## Individual recoverability

No isolated silo recovers any required multi-silo explanation.

This test is structural: once only one silo's Evidence remains, no candidate
retains the minimum three-silo ancestry required for a non-local explanation.

## Evidence-removal results

For each four-silo positive scenario:

- removing one silo preserves the candidate but reduces confidence by
  `0.0448`;
- removing any two silos invalidates the candidate.

For the three-silo reconciliation scenario:

- removing any one required silo invalidates the candidate.

This demonstrates compositional sensitivity rather than simple Evidence-volume
reward.

## Local interpretations

Each positive scenario contains plausible local explanations. Examples:

- shrinking margin appears to be pricing;
- delivery delay appears to be capacity;
- late implementation appears to be staffing;
- changing requirements appear to be either Product or Engineering failure.

The integrated explanation retains these as locally plausible symptoms while
identifying the cross-functional Mechanism that connects them. No input
observation contains the complete integrated explanation.

## Held-out predictions and interventions

Predictions and interventions are registered before future reveal. Structured
models correctly predict all five positive outcomes and select all five
effective interventions.

Individual, majority, summary, and State models do not identify the canonical
Mechanism and therefore cannot select the mechanism-specific intervention.

## Final questions

1. **Can Discovery generate explanations unavailable to an individual silo?**
   The structured benchmark path does; current production generation remains
   unproven.
2. **Does cross-silo synthesis outperform generic summarization?** Yes,
   `1.000000` versus `0.444444` on prediction and intervention.
3. **Does structured cognition outperform all-evidence summarization?** Yes in
   this controlled benchmark.
4. **Which canonical components matter most?** Mechanisms and Evidence lineage.
   History contributes to confidence; Theory and Conditions corroborate.
5. **Which evidence combinations are necessary?** Three independent silos
   minimum; four-silo cases survive one removal but not two.
6. **Does emergence improve predictions?** Structured cross-silo cognition
   does; the Emergent projection does not improve on Canonical Combined.
7. **Does emergence improve intervention selection?** The structured mechanism
   does; the projection adds no further value.
8. **Nonlinear understanding or aggregation?** The mechanism is relational and
   compositionally sensitive, exceeding concatenation. Because the fixture
   provides that Mechanism, end-to-end nonlinear production generation is not
   yet demonstrated.

## Recommendation

Do not add Emergent Intelligence, Organizational Intelligence, Meta Reasoning,
or Cross-Silo Cognition to the canonical chain.

Treat this as controlled evidence that existing structured Mechanisms can carry
Emergent Organizational Intelligence when they preserve cross-silo ancestry.
The next legitimate gate is a production-shadow replay that begins with raw
silo Evidence and tests whether unchanged production producers generate the
same cross-silo Mechanisms without benchmark-authored relational structure.

Until that replay passes, describe Discovery as demonstrating emergent value in
a controlled production-shaped benchmark—not as proven end-to-end emergent
organizational intelligence.
