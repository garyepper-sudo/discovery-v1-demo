# Candidate Enriched Mechanism Shadow Experiment 001

## Purpose

Test whether existing production-generated cognition can populate a richer,
safer Mechanism representation without inventing causal structure.

Prior audits found useful cross-silo fragments, incomplete Mechanism fields,
generic downstream handoffs, and an insufficient-evidence false positive. This
experiment tests representation feasibility before any production type or
ancestry proposal.

## Input boundary

Twelve scenarios begin with raw Evidence and execute unchanged:

```text
runDiscoveryV3()
→ evolveOrganizationRuntime()
```

Enrichment may consume only generated Observations, Signals, Themes,
Phenomena, Contradictions, Mechanisms, Beliefs, Concepts, Theories,
Conditions, Organizational State, Predictions, confidence, and Evidence
lineage. Scoring truth is withheld until registration.

## Strategies

1. Current Mechanism projection.
2. Mechanism plus direct lineage.
3. Full canonical context.
4. Conservative context retaining only explicit or deterministically derived
   fields.

Every field records derivation status, source artifacts, Evidence lineage,
production stage, derivation rule, ambiguity, temporal dependence, and
cross-silo dependence.

## Contracts

The fixed contracts are current production, structural minimum, mediated
hypothesis, qualified causal mechanism, and conservative qualification. The
shared confidence threshold is `0.70`. Rules never vary by scenario.

## Scenarios and controls

Six positive families cover commercial complexity, escalation, local
optimization, customer misdiagnosis, delayed consequence, and contradictory
local explanations. Six negative or underdetermined controls cover
insufficient Evidence, high connectivity, correlation, one-silo explanation,
structural change, and redundant confirmation.

Counterfactuals remove a central bridge, restore complementary Evidence, add
redundancy, add low-quality conflict, reverse temporal order, and remove
candidate fields or lineage.

## Run

```bash
npx tsx engine/benchmark/candidate-enriched-mechanism-shadow-experiment-001/runCandidateEnrichedMechanismShadowExperiment001.ts
```

## Limitations

- Synthetic scenarios cannot establish real-world sufficiency.
- Exact textual overlap is required for deterministic implication recovery.
- Ambiguous contradictions are retained only by full-context enrichment and
  cannot qualify conservative candidates.
- Missing fields remain empty; plausible prose is never substituted.
- This experiment does not authorize production schemas, producers,
  qualification scores, or downstream ancestry.
