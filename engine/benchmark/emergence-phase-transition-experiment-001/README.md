# Emergence Phase Transition Experiment 001

## Objective

Test whether unchanged production cognition exhibits a reproducible relational
boundary between distributed organizational information and supportable
organizational understanding.

The prior production-shadow experiment found equal mean Evidence counts and
silo counts in successful and failed mechanism cases. This experiment
therefore varies relationship structure directly while holding quantity,
source balance, reliability, time span, and vocabulary approximately constant
where required.

## Production replay

Every configuration starts as production-shaped raw Evidence and enters:

```text
runDiscoveryV3()
→ evolveOrganizationRuntime()
```

A fixed clock and a fresh in-memory Runtime preserve determinism and prevent
persistence. Production generates Evidence, Signals, Themes, Observations,
Contradictions, Mechanisms, Beliefs, Phenomena, Concepts, Theories,
Organizational Conditions, and Organizational State.

Benchmark adapters perform deterministic ordering, lineage-to-silo mapping,
analysis-only graph construction, scoring, and verbal projection. They do not
add a relationship, mechanism, answer, or expected label.

## Design

Four independent families cover commercial complexity, decision escalation,
local optimization, and customer workflow misdiagnosis. Eighty-four
configurations include:

- five-stage incremental relationship reveals;
- constant-count connected/disconnected topology pairs;
- bridge and peripheral removals;
- equal-count redundancy, complementarity, and noise controls;
- three-level noise sweeps;
- three-level alternative-mechanism competition;
- correct, ambiguous, reverse, and absent temporal order.

The analysis graph derives only:

- Evidence-to-silo membership;
- lexical overlap between raw Evidence;
- timestamp precedence;
- production-generated Evidence-to-Mechanism lineage.

Scoring truth never reaches production cognition or graph construction.

## Operational emergence criteria

A result emerges only if it passes non-locality, relational novelty,
cross-silo necessity, mechanistic completeness, discriminability, held-out
prediction, intervention selection, groundedness, and counterfactual
sensitivity. Confidence alone cannot pass the benchmark.

## Run

```bash
npx tsx engine/benchmark/emergence-phase-transition-experiment-001/runEmergencePhaseTransitionExperiment001.ts
```

The runner writes deterministic `RESULTS.json` and internally verifies repeated
execution plus reversed configuration, Evidence, silo, and within-silo order.

## Limitations

- Fixtures are synthetic and deliberately small.
- Lexical overlap is a transparent but incomplete proxy for semantic linkage.
- Matched topology pairs allow a 50% character-volume tolerance.
- Threshold scans are one-dimensional and strongly affected by class imbalance.
- No configuration passed all operational criteria, so the benchmark cannot
  estimate a positive transition threshold.
- The experiment neither defines nor authorizes a production emergence metric.
