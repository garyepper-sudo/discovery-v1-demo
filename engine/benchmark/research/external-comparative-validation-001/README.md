# External Comparative Validation 001

**Status:** Benchmark-only Phase 0 research

**Gap:** `GAP-D-005`

**Roadmap:** Research track; no production promotion

This experiment compares externally observable organizational-understanding
quality across a human import boundary, a deterministic fixture-backed generic
synthesis proxy, deterministic lexical retrieval plus synthesis, deterministic
structured analysis, and canonical Discovery.

It does not change architecture. It reuses the canonical Discovery engine as a
black-box treatment and keeps every benchmark adapter under research ownership.
No Runtime persistence, product contract, route, frontend, authorization, or
customer behavior imports this directory.

The preregistration is frozen before treatment execution. A defect discovered
after execution begins invalidates the affected case; ground truth and weights
must not be repaired post hoc.

The LLM proxy is not a genuine external-model result. Human-only remains
`not-yet-evaluated` until blinded responses are imported. Consequently Phase 0
cannot demonstrate external comparative advantage by itself.
