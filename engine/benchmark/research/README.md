## Local Understanding Utility

Local Understanding Utility is an optional benchmark-only research profile
for a named experiment and protocol. It describes whether a bounded treatment
improved useful local understanding under that experiment's native measures,
controls, and ablations.

It sits beneath the Organizational Understanding Index and before any User
Intelligence claim. It is not:

- a sixth Discovery Scorecard metric;
- a permanent weighted formula;
- comparable across unrelated experiments without a separate protocol;
- a production object or capability;
- evidence that users or the organization became more intelligent.
