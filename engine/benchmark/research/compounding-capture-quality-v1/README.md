# Compounding and Capture-Quality Instrumentation V1

`SYNTHETIC BENCHMARK — NOT CUSTOMER OR PRODUCTION EVIDENCE`

This GAP-D-005 research lane is a noncanonical, read-only measurement projection. It adds no Product route, store, event, background telemetry, network export, or persona-specific truth. `MeetingUnderstandingCycleObservationV1` uses only content-safe digests, counts, revisions, and explicit metadata after current-access and exact organization/user/series/occurrence checks.

Run `npm run research:compounding-capture-quality -- <explicit-output-root>` to generate the complete evidence bundle in a caller-owned isolated directory. There is intentionally no default output directory: large, reproducible corpus, ledger, observation, and packet artifacts are not stored in Git. `ACCEPTED_FULL_BUNDLE_LEDGER.json` anchors the accepted 15-file bundle by exact byte size, SHA-256, aggregate digest, and row/packet counts. The compact checked-in evidence remains independently inspectable.

Run `npm run validate:compounding-capture-quality` for deterministic, privacy, fairness, leakage, replay, two-clean-root byte equality, accepted-ledger, and retained-compact-byte checks. `exportObservations.ts` is an explicit operator-only API: callers must supply currently authorized metadata; it never loads protected bodies itself.

The corpus comprises three synthetic contexts (sales pipeline, product delivery, marketing agency), eight cycles, five preregistered seeds, two estimated-context budgets, four paired conditions, and five reviewed-state quality variants. It includes chronology, supersession, decisions/non-decisions, commitments, outcomes, assumptions, contradictions, questions, noise, duplicates, authority, rejection, correction, and permission boundaries. Model packets and grader/hidden-truth packets are separate files.

## Claim boundary

The benchmark tests structural information availability and context efficiency. It does not test model behavior, user value, customer behavior, or organizational outcomes. Model-mediated quality compounding: **NOT TESTED**. Authentic customer compounding: **NOT TESTED**.
