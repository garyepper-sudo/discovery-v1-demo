# Organizational Objective Discovery Experiment 001

Benchmark-only research comparing seven deterministic ways to discover an organizational objective. The experiment consumes authored signals and expected outcomes; it does not import Runtime, cognition, Product Communication, or recommendation production code.

Run:

```bash
npm run experiment:organizational-objective-discovery-001
npm run validate:organizational-objective-discovery-001
```

The benchmark is synthetic architectural evidence. It tests whether a design preserves objective candidates, authority, ambiguity, change, and question efficiency. It does not establish production performance or authorize an objective.
