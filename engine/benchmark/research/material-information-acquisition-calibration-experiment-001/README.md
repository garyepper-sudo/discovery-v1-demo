# Material Information Acquisition Calibration Experiment 001

Shadow-calibration research for the non-persistent Material Information Acquisition contract. It compares eight selectors over separate calibration, validation, holdout, and negative-control fixtures, plus ten four-round sequential scenarios.

```bash
npm run experiment:material-information-acquisition-calibration-001
npm run validate:material-information-acquisition-calibration-001
```

All counterfactual outcomes are benchmark fixtures. No Runtime, Product Workflow, connector, action owner, or production selector is imported or mutated.
