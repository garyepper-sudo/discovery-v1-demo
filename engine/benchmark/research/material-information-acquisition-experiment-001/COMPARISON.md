# Material Information Acquisition Comparison

| Strategy | Useful property | Structural failure |
| --- | --- | --- |
| Fixed workflow | Predictable | Ignores action-specific value and burden |
| Always ask | Can resolve preferences and authority | Repeats known questions and overloads users |
| Always search | Low interruption when evidence exists | Cannot resolve preference, authority, or missing measurement |
| Rule priorities | Governable and simple | Static order misses context-dependent tradeoffs |
| Expected information gain | Targets uncertainty reduction | Ignores downstream value, authority, reliability, and cost |
| Expected organizational value | Connects learning to consequences | Can favor speculative or prohibited acquisition |
| Governed hybrid | Evaluates all action types through one boundary | Requires calibrated attributes and explicit policy before production |

No additional action type is architecturally required by this experiment. Connector search, document request, survey, measurement, experiment, Outcome waiting, stopping, and abstention cover the discriminating cases; future actions can implement the same contract if they add distinct acquisition semantics.
