# Canonical Organizational Understanding Ownership Migration

## Decision

**A — CANONICAL OWNERSHIP MIGRATION COMPLETE**

Discovery 2 Phase 4C promotes the validated Category A contract to the
canonical production owner for reusable Organizational Understanding.

## Ownership Boundary

Completed Organizational Explanations continue to own explanatory claims,
Evidence ancestry and comparative roles, assumptions, role availability,
Explanation identity, and unadjudicated viability.

Canonical Organizational Understanding now owns governed composition and
organizational scope, outcome and Explanation membership, composition
uncertainty, stable revision identity, and reusable organizational truth.

The canonical compositions persist once at
`OrganizationRuntime.memory.organizationalUnderstandingState.canonicalCompositions`.
The historical `currentUnderstandings` field remains an assessment-derived
compatibility view. The nested organizational-memory compatibility mirror does
not duplicate canonical compositions.

Executive Assessment is a downstream consumer of canonical Organizational
Understanding. Its output contract and all existing recommendation,
communication, projection, and product consumers remain unchanged.

## Compatibility and Rollback

The migration is additive. Historical Runtime records without
`canonicalCompositions` remain readable and replayable without fabricated
ancestry. The temporary `legacy` ownership mode is the explicit rollback
boundary and reproduces the pre-migration Runtime byte-for-byte.

The implementation retains bounded compatibility adapters while current
consumers migrate. It does not activate Explanation adjudication, change
authority or disclosure semantics, redesign persistence, or promote benchmark
research into production.

## Benchmark Result

`npm run benchmark:canonical-understanding-ownership-migration` passes
`14/14`.

The gate verifies canonical activation, rollback equality, a single persisted
owner, reference-only Explanation membership, unchanged completed
Explanations, downstream Executive Assessment, unchanged compatibility and
application views, deterministic replay, historical compatibility, no
benchmark dependency, and no new Runtime store.
